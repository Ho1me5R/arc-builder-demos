# Arc ERC-8004 AI Agent Registration

A learning demo for testing Arc's ERC-8004 AI agent registration flow using Circle Developer Console and developer-controlled wallets.

## What this demo does

This demo follows the official Arc tutorial to register an AI agent identity on Arc Testnet.

The flow includes:

- creating developer-controlled wallets
- registering an agent identity
- retrieving an Agent ID
- recording reputation
- requesting validation
- completing validation
